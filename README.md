# Michael Smith's Dotfiles

My personal configuration files, managed as a bare git repo checked out against `$HOME`.
No symlinks required

## Setup on a new machine
Clone the repo as a bare repo directly into `$HOME`:
```bash
git clone  --bare https://github.com/msmith-codes/.dotfiles.git $HOME/.dotfiles
```

Source the .bashrc file
```bash
source ~/.bashrc
```
